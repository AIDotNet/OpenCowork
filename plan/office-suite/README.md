## 三句话结论

1. **当前实现不是"保真度不够"，而是架构上不具备保真的可能性。**
   文档在系统里的类型是 `string`，而 OOXML 是一个 ZIP 包。
   这个类型错误导致：xlsx **保存即毁档**、docx 只读、**本地 pptx 零预览**、
   Agent **完全读不到任何 Office 文件**。

2. **修复的关键不是换渲染引擎，是换文档的存在形式** ——
   从"读成字符串"变成"打开一个有版本的会话"，编辑走增量 op，
   保存做**部件级保留**（未触及的部件逐字节原样回写）。
   做对这一步，图表/透视表/VBA/数据验证即使我们完全不理解也不会被破坏；
   不做这一步，换任何引擎都会重蹈覆辙。

3. **"跟微软完全一样"要分格式回答**：Sheet 能做到实用等价（自研 canvas 网格），
   Slide 能做到很接近（pptx → SVG），
   **Word 做不到** —— 分页排版是排版引擎级问题，
   只能靠 LibreOffice headless 出保真页 + 结构化编辑器改内容的双模方案。

## 最紧急的一件事

`spreadsheet-viewer.tsx:93-104` 用 `book_new()` + `aoa_to_sheet` **从零重建**工作簿。
点一次 Save，原文件的公式、数字类型、样式、合并、列宽、条件格式、
**数据验证下拉**、图表、图片、透视表、批注、VBA **全部永久丢失**，且无任何提示。

配套还有：工作簿模式 undo/redo 直接 `return`（`:236,247`）、
不设 `modified` 标记所以关闭时不提示、全局 Save 对工作簿禁用。

这个缺陷独立于整个重构计划，**建议立刻止血**（见 05 文档 M0）。
