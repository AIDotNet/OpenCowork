## M1 · 会话协议 + 部件级保留（核心，2–3 周）

**先做 spike（1–2 天，结论决定后面的实现形态）**：
`DocumentFormat.OpenXml` 在 NativeAOT 下是否可用？
本仓库已有 AOT 下异常消息退化为资源键的先例，反射重的库风险高。
**倾向结论**：手写 `System.IO.Compression` + `XmlReader/XmlWriter`，
`FileDocumentTools.cs:53-122` 已经在用这个路数，且部件级保留天生只需动少数部件。

然后：

- `Modules/Document/`：`DocumentModule` / `SessionStore` / `OoxmlPackage` /
  `SheetAdapter` / `PatchEngine` / `FileGuard`
- `doc/*` RPC + main 侧 `document-handlers.ts` + 跨窗口 `doc/changed` 扇出
- 渲染层 `DocumentClient` + `DocumentHost`（UI 先沿用现有网格外观，只换数据通路）

**验收（必须是自动化单测）**：

> 打开 → 不编辑 → 保存，输出 ZIP 与输入**逐部件字节相等**（`docProps/app.xml` 除外）。
> 语料至少覆盖：带公式、带图表、带透视表、带数据验证、带 VBA、带条件格式、带批注的工作簿各一份。
> 再加一份就是截图里那种真实的"工时补录"模板。

**M1 结束时"保存即毁档"消失** —— 这是整个计划的价值拐点，
后面的都是体验提升，这一步是止损。

## 风险登记

| 风险                                             | 影响                                | 应对                                                                                                         |
| ------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **`DocumentFormat.OpenXml` AOT 不兼容**          | M1 实现形态推翻                     | M1 第一件事就 spike；备选手写 XML（已有先例，且部件级设计只需动少数部件）                                    |
| **部件级保留不变式漏洞**                         | 仍会毁档，但更隐蔽                  | 不变式单测 + 真实语料库；首次保存前自动 `.bak`                                                               |
| **LibreOffice 许可（LGPLv3）**                   | 商业发行合规                        | **不静态链接、不打进安装器**：独立可执行文件 + CLI 调用 + 用户按需下载，是最干净的法律姿态。发行前需法务确认 |
| **Univer OOXML 导入导出是 Pro（商业+需服务端）** | 若选 Univer，OSS 路径仍要自写适配器 | 已据此**不选** Univer：适配器省不掉，反而多一层模型映射和大依赖                                              |
| **canvas 网格工作量被低估**                      | M2 延期                             | M2 可切分：先虚拟化+样式+合并（覆盖 80% 场景），公式栏/条件格式/图表 overlay 二期                            |
| **包体膨胀**                                     | 下载体验                            | 引擎按 `documentProviders` 懒加载；LibreOffice 永不进包                                                      |
| **Agent 与用户并发写同一文档**                   | 冲突丢改动                          | revision + baseRevision + rebase；冲突时 UI 明确选择，不静默覆盖                                             |
| **`use-file-watcher` 的 `fileVersion` 整份重读** | 抹掉正在编辑的内容                  | `DocumentHost` 必须退出该机制，改订 `doc/external-change`                                                    |
| **cron 静默过滤新工具**                          | 定时任务里文档工具无声失效          | M4 必须一并改 cron 的取列表方式，不能只加 `BACKGROUND_TOOL_DEFINITIONS`                                      |
